# Nirooi Adelli Inventory Ledger

A responsive React + TypeScript restaurant inventory and daily ledger app, modeled on the supplied mobile video.

## Start locally

```sh
npm install
npm run dev
```

Vite prints the local address to open in a browser. To make a production bundle, run `npm run build`.

## Included pages

- Dashboard with revenue, expense, stock health, and recent ledger activity
- Stock sheet with category filtering, search, inline quantity edits, item add/edit, and CSV export
- Invoice register with upload details, status filters, and payment status toggling
- Daily sales and expense ledger with transaction entry
- Supplier directory with locally saved vendors
- Sale preview, sales and stock reports, priorities, purchase estimation, schedule, and settings

The sample records are stored in the browser's local storage. This project does not include a remote database or user authentication.
